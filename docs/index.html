Research date 2026-11-18

No single project does this today

The question: is there an open-source, Siri-like assistant that runs on local models, reaches your apps with real permissions and carries long tasks unattended, on Apple Silicon Mac minis and Linux? As of 2026-11-18, no. The parts exist. The integration does not.

Research date: 2026-11-18. This field moves monthly. Versions, star counts and benchmark figures were read on that date and will go stale. Every claim carries a confidence label, and what could not be verified is listed in one place.

What comes closest

Two projects come close enough that building a new agent from scratch would be a mistake.

  • Hermes Agent (Nous Research, MIT) is the closest match. It has chat, a voice mode, an on-device wake word, a managed local llama.cpp runtime, a durable cron scheduler, a task board, persistent goals, memory, macOS skills for iMessage, Reminders and Notes, and desktop apps on macOS, Windows and Linux [1][2][3][4][5].
  • OpenClaw (OpenClaw Foundation, MIT) is the other. It has a macOS companion app that brokers system permissions and voice wake, more than 20 messaging channels including iMessage, and optional Docker sandboxing [6][7][8].

There are two different things called Hermes. The Hermes model line has not had a release since Hermes 4.3 36B in November 2025 [15]. Hermes Agent is the harness, and it is very active (v0.23.2 on 2026-11-16) [1]. Today, "Hermes underneath" should mean Hermes Agent running a Qwen or Gemma model, not a Hermes model. The full survey is on the landscape page.

What is missing

Neither project has these, and nothing else found does either.

  1. A real per-app, per-action permission model enforced by the operating system rather than by the agent's own allowlists. On macOS the practical grant for Messages and Mail data is still Full Disk Access, which Apple itself is now restricting because of AI agents [9][10].
  2. Parity on Linux for personal data. Calendar, reminders, notes and messages on Linux are reachable only through scattered community bridges with unclear permission boundaries [11].
  3. A local model reliable enough for multi-hour unattended work on a 16 to 64 GB machine. The harnesses are ready; the models that fit are not [12][13][14].
  4. A tested, documented combination of all the layers (model, runtime, voice, integrations, scheduler, guardrails) for Apple Silicon minis plus Linux clients.

The gap is the integration, the permission model, the review queue and the Linux side. That is what the roadmap is about.

The recommended shape: hybrid, with a Mac mini as the hub

Keep the Mac mini on macOS as the data and inference hub, because iMessage, Reminders and Notes access is macOS only and M4 minis have no GPU inference under Linux. Pin a small model for voice and chat, swap in a work model for checkable jobs, send hard unattended jobs to a hosted model, and let nothing send or merge without passing a review queue. Mac and Linux machines are thin clients.

What goes local and what goes hosted

The routing rule is what makes the hybrid safe. It puts the unreliable component, the local model, only where its output is cheap to check.

Class of work Route Reason
Voice turns, quick questions Small local model, pinned Latency and privacy
Anything that reads messages, mail, calendar, notes Local model only Private data stays in the house
Drafting replies Local model writes to a review queue; nothing sends without approval Enforcement outside the model; see draft but do not send
Upstream triage, labelling, digests Local model plus deterministic rules, report-only The model labels, code decides; checkable
Nightly repo clean-ups, multi-file changes, investigations Hosted frontier model through Claude Code or Codex CLI in a sandbox, PR-only, with a spend cap Local models that fit in 64 GB are well behind on long-horizon work
Fallback when hosted is down or over budget Local work model, report-only Degrade safely

Hermes Agent expresses this with a main model, fallback_providers, cron.model and per-job pins [2]. The reasoning behind each row is on the models page and the build page.

Status

This project is research and a roadmap, plus one piece of software: an evaluation lab that measures a small local model on assistant tasks. The assistant itself is not built. The research was done on 2026-11-18; nothing here has been re-checked since.
